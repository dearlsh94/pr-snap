PR-Snap

Quickly copy GitHub pull request links with titles in various formats for easy sharing.

How to use:
  • Click the copy icon in PR page header
  • Or use keyboard shortcut
Format Settings
Keyboard Shortcut

Set your preferred shortcut in browser's extension settings:

  • Chrome: chrome://extensions/shortcuts
  • Arc: arc://extensions/shortcuts
  • Comet: comet://extensions/shortcuts
